## 编制原则

- **时间窗**：2026-10-01 至 2026-10-09。9 月底发布、10 月才发酵的事件（GPT-6 Astra 首发 09-04、Gemini 4 Argon 09-30、英伟达收购 Hugging Face 09-03）单独标注，不计入本月事件。
- **全部实时检索**：本文件不依赖模型记忆，所有条目均通过公开报道现查现核。
- **口径冲突不掩盖**：同一件事不同媒体数字不一致时，两种口径并列写出并标"存疑"，不做取舍粉饰。

- **视频**：不下载视频文件，只给出可跳转的视频 / 播客 / 官方演示链接。
